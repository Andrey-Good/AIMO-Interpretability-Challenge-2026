# Исследовать вопрос, не проходить стадии

Адаптация scientific-brainstorming / scientific-critical-thinking K-Dense;
[происхождение и изменения](../SOURCES.md). Это ориентиры, не обязательный цикл.

Начни с того, что сейчас неизвестно. Если пользователь только размышляет, обсуждай;
если просит план — предложи небольшой проверяемый опыт; если появились данные —
пересмотри объяснение. План можно менять и прерывать, отмечая значимые отклонения.
Не создавай документ ради обсуждения: решение, важное для команды, запиши рядом с опытом.

Содержательное планирование делает researcher (Astra high). Передай ему исходный вопрос,
факты, ресурсы и ограничения без навязанного желаемого ответа. При реальной развилке
новый исследователь может независимо предложить альтернативу. Не считай согласие моделей
доказательством; прекращай спор, когда различить версии можно только измерением.
Если high действительно недостаточно, координатор может явно создать обычного default-агента
с Astra xhigh; max — лишь при оправданной цене ошибки. Файл researcher закрепляет high,
поэтому простая просьба «та же роль на xhigh» настройку не меняет. Не эскалировать для рутины.

Для опыта достаточно понимать: вопрос; что взяли у LLM; чем сравниваем; единицу данных;
что опровергнет предположение; доступный бюджет. Не требуй полей без практической пользы.
Устойчивость относится к модели и задаче, а не только к математическому условию.
Формулировки одной исходной задачи — одна группа при разделении train/validation.
Точная строка не заменяет family_id. Метки не передаются извлечению признаков.
Нормировка/PCA/выбор признаков учатся внутри train; окончательная выборка — не для подбора.

Начни с дешёвого сравнения и простого предсказателя. Сложность добавляй, если она отвечает
на вопрос. Для сравнения голов сохраняй разбиение и бюджет; для важных признаков убери
группу и переобучи, а не просто объяви большие веса важными. При сканировании многих
слоёв сохраняй все попытки и подтверждай находку на новых независимых данных.
Объясни результат как «что наблюдали → какие объяснения остались → что проверить дальше».
