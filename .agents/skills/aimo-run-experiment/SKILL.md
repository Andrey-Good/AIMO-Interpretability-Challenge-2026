# aimo-run-experiment

Вход: путь уже проверенной experiment plan и разрешение пользователя на эту область.
1. Проверить approval, run_id, данные/split/spec, точную команду, лимит времени,
   устройство и ожидаемые результаты. Pending/UNSET/грязное дерево — стоп.
2. Сначала коммит кода+карточки. Из чистого дерева вызвать:
   python tools/agent_ops/run_experiment.py research/experiments/<id>.plan.json
3. Не обходить lock, не запускать несколько копий вручную, не увеличивать время/GPU
   без разрешения. Работа runner не запрещает сеть и не является полным sandbox.
4. При NaN/OOM/утечке остановить серию. Не «лечить» сменой меток или тихим снижением
   выборки. Повтор — новый run_id с новой причиной; частичные данные сохранить отдельно.
5. После завершения проверить ожидаемые артефакты, выполнить aimo-review-results.
   Даже failed/interrupted фиксируется отдельным result-коммитом после проверки приватности.
6. Не идти к следующему опыту до коммита записи. Не заявлять scientific success по exit=0.

Выход: execution.json + человеческий report.md + commit, либо точный блокер.
Автономия относится лишь к заранее разрешённой серии, а не к бесконечному поиску.
