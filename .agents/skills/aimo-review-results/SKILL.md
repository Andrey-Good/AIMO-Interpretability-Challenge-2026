# aimo-review-results

Обычно aimo-reviewer (Astra high). Автор реализации не заменяет внешнюю проверку.
1. Получить исходную карточку, код SHA, execution record, разрешённые результаты
   и формулировку вывода. По возможности факты прочитать до объяснения автора.
2. Проверить число независимых задач, группы разбиения, baseline, знаменатели,
   порядок IDs, train-only fitting, подбор порога и число попыток.
3. Пересчитать важную метрику из разрешённых прогнозов/меток либо явно сказать,
   почему независимо не пересчитано. Проверить ручной тензорный пример для новой формулы.
4. Сопоставить с простыми альтернативами (длина, тема, уверенность). Хороший decoder
   не доказывает причинную роль активации. Повтор seeds не заменяет новые задачи.
5. Интервалы разброса считать по независимым группам. Отмечать слабую статистическую
   мощность вместо «различий нет» по одному незначимому тесту.
6. Вернуть verdict: blocked / exploratory / supported-with-caveats / replicated.
   Для каждого blocker — файл/команда/свидетельство, исправление и повторная проверка.

Не менять код/метки, не подписывать approval за человека. Неизвестное оставлять
неизвестным. Если фактически это саморевью, так и назвать его.
