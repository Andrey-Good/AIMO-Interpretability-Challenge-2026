# aimo-memory-handoff

Вход: конкретные run/commit, отчёт проверки, разрешённый файл записи.
1. Записать вопрос, изменения, настоящие команды/исходы, вывод, ограничения,
   отрицательные результаты и один следующий шаг.
2. Для наблюдения указать источник/run_id, scope (модель/данные/spec) и статус.
   Гипотеза ≠ наблюдение ≠ повторено. Подмена статуса требует отдельного свидетельства.
3. Не копировать весь чат. Не сохранять личные сведения, секреты, закрытые условия
   и сырые токены/активации. Ссылки и контрольные суммы должны быть разрешены к публикации.
4. Рабочий агент пишет отдельный MEMORY/handoffs/<task_id>.md. Только координатор
   интегрирует MEMORY/STATE.md/DECISIONS.md, предотвращая конфликт нескольких веток.
5. Опровергнутый результат не удалять: пометить новым свидетельством и ссылкой.
   Эксперименты и старые code SHA сохранить до squash/удаления ветки.

Выход: компактный воспроизводимый handoff/record, без недоказанных новых выводов.
Личная встроенная память ~/.codex/memories не заменяет этот командный источник.
