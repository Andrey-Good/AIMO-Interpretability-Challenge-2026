# Навыки проекта

Это **11 навыков**, а не 11 всегда работающих агентов. Codex сначала видит имя/описание
и загружает полный SKILL.md по необходимости. В CLI/IDE можно вызвать `$имя-навыка`;
в приложении — через доступный выбор навыков. Проверить обнаружение после открытия
доверенного проекта; наличие файлов ещё не доказывает успешный live-trigger в клиенте.

## Наши процедуры AIMO

- [aimo-research-cycle](aimo-research-cycle/SKILL.md) — Сформулировать проверяемую гипотезу и ограниченный опыт AIMO; использовать для научного планирования и разбора следующих шагов, не для механической правки.
- [aimo-literature-review](aimo-literature-review/SKILL.md) — Найти и проверить научные статьи или документацию для конкретной гипотезы AIMO; не использовать вместо проверки результатов на наших данных.
- [aimo-data-audit](aimo-data-audit/SKILL.md) — Проверить схему AIMO, метки, дубли и разделение родственных задач до обучения; также для расследования утечки данных или несравнимых метрик.
- [aimo-feature-extraction](aimo-feature-extraction/SKILL.md) — Реализовать или проверить извлечение состояний, разброса перефразов и неопределённости токенов; сохранять научные операции явно, не заниматься загрузкой данных.
- [aimo-predictor-study](aimo-predictor-study/SKILL.md) — Сравнить головы, отбор признаков и размеры модели на фиксированном разбиении; применять после согласования признаков, а не менять датасет ради score.
- [aimo-implementation](aimo-implementation/SKILL.md) — Написать или исправить научный код AIMO по согласованному контракту; использовать для scoped реализации и тестов без самостоятельного изменения гипотезы.
- [aimo-run-experiment](aimo-run-experiment/SKILL.md) — Запустить конкретный согласованный опыт AIMO с лимитами и журналом; только по явному запросу, не использовать для общей идеи или чтения результатов.
- [aimo-review-results](aimo-review-results/SKILL.md) — Независимо проверить метрики, утечку, формы и научный вывод AIMO перед признанием результата; не использовать как церемониальное одобрение чужого отчёта.
- [aimo-memory-handoff](aimo-memory-handoff/SKILL.md) — Записать проверенный результат или передать контекст AIMO после задачи; не превращать предположения агента в факты и не переписывать общую память параллельно.
- [aimo-report](aimo-report/SKILL.md) — Представить результаты AIMO исследователю простым языком и с доказательствами; для отчётов/графиков, а не самостоятельного запуска новых опытов.

## Официальный навык OpenAI

[define-goal](define-goal/SKILL.md) — сформулировать измеримую цель. Сохранён из
openai/skills с лицензией и происхождением. Это не наш авторский AIMO-skill.
Его get_goal/create_goal следует вызывать **только если реальный клиент предоставляет
эти инструменты**, и только когда пользователь явно просит цель. Иначе записать
карточку через aimo-research-cycle; не придумывать tool calls.
Официальный skill не ведёт журнал — это делает aimo-memory-handoff.

Навыки не ставят пакеты, не добавляют API-ключи и не расширяют права.
У aimo-run-experiment запрещён неявный вызов в метаданных; это дополнительная защита,
не замена approval в карточке и runtime permissions. Остальные процедуры без исполняемых
установщиков; читать их перед использованием. Сторонние сетевые навыки не скачивались.

В каталоге OpenAI также рассмотрены jupyter-notebook и gh-fix-ci, но они не нужны
для первого научного пути и не установлены «на всякий случай». Новый полезный skill
добавлять с задачей, происхождением, тестовыми запросами и проверкой кода/лицензии.
