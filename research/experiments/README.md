# Карточки опытов

`example.plan.json` — незапускаемый образец с нулевым разрешением.
Создай новую папку/файл с уникальным run_id, согласуй содержимое с человеком,
заполни фактическую среду, зафиксируй коммитом и запускай через recorder.
В argv используй `{python}` для текущего Python; все остальные значения — буквальные аргументы.
Не помещать секреты и тексты закрытых задач в argv.

```bash
python tools/agent_ops/run_experiment.py research/experiments/E-depth-001/plan.json
```

Это универсальный ограниченный запуск уже существующей команды, не готовый train CLI.
Карточка approval фиксирует согласование, но сама не может доказать авторство человека.
Никакого автоматического заполнения `approved_by` агентом вместо пользователя.
