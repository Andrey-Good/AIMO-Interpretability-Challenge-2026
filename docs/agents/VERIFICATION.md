# Проверка этого изменения

Дата: 2026-09-07. База: `ca369172848ecb483c5f8a5f011849c266bb54dd`.
Проверки ниже относятся к новым файлам, не к неизменённому starter-kit.

## Что выполнено

Локальная среда Linux, Python 3.13.5, PyTorch 2.10.0+cpu, CUDA недоступна.
Это не конкурсный контейнер с закреплёнными версиями.

```bash
python tools/agent_ops/check_setup.py
python -m unittest discover -s tools/agent_ops/tests -v
OMP_NUM_THREADS=1 MKL_NUM_THREADS=1 python -m unittest discover -s research/tests -v
```

Последняя команда ограничивает число CPU-потоков только у тестового процесса.
На Windows можно запустить обычный `python -m unittest ...` без POSIX-префикса.

Результат: 20 проверок обвязки/настроек и 16 проверок научного ядра прошли.
Среди проверок: соответствие последнего токена маске слева/справа; отсутствие градиентов
LLM; сохранение порядка; ручной ожидаемый тензор; обучение головы на искусственном примере;
отказ при pending/UNSET/грязном дереве; таймаут; ошибка процесса; отсутствие выхода;
неперезапись попытки/старого результата; lock между реальными temporary git worktrees;
контроль изменения исходников; хеш файла результата.

Синтаксис Python/JSON/TOML, локальные Markdown-ссылки новой части, обязательные поля
навыков/ролей и политика sandbox проверены. SKILL.md define-goal и openai.yaml совпали
с Git blob SHA источника; полная лицензия Apache-2.0 включена отдельно.
Статическая проверка не является полной валидацией конфигурации бинарником Codex.

На промежуточной проверке были обнаружены три проблемы локальных ссылок: два неверных
относительных пути в каталоге навыков и ещё не созданный этот документ. Исправлены;
при добавлении проверки хеша также исправлено экранирование строки теста.
После исправлений относящиеся к ним проверки выполнены снова. Это технические тесты, не AIMO runs.

## Что НЕ выполнено

Реальный Codex и маршрутизация навыков/подагентов не запускались; модели Astra/Terra/Luna
в этом проекте не сравнивались. Настройки подтверждены текущими официальными страницами,
но их применение на аккаунте пользователя ещё требуется проверить через его клиент.
Настоящих независимых подагентов в этой сессии не использовалось; проверка была локальной.

Не запускались LLM/checkpoint, GPU, настоящий AIMO dataset, конкурсный Docker,
весь старый test suite, экспорт solution ZIP или отправка на Codabench.
Windows-остановка дерева процессов в runner подготовлена, но не проверена на Windows.
Runner не ограничивает VRAM/API-кредиты/сеть и не защищает от враждебного кода.
Он не включает сам себя в автозапуск и не предоставляет GPU.

Полноценные загрузчик/feature-cache/train CLI/solution adapter остаются следующей
задачей. Прозрачные функции уже существуют и проверены на маленьких тензорах;
не выдавать их наличие за готовый исследовательский конвейер или научный результат.

## После получения коммита

Открыть доверенный проект в актуальном Codex, проверить модель/effort и обнаружение
ролей/навыков. Пройти один dry-run без GPU. Только затем согласовать отдельную
карточку первого маленького опыта с реальными данными и вычислительным бюджетом.
