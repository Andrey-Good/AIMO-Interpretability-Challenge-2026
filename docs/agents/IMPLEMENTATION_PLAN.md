# План создания правил исследовательского репозитория

Дата: 2026-09-07. База: `ca369172848ecb483c5f8a5f011849c266bb54dd`.

## 1. План подготовки плана

Выделить требования пользователя: видимый вычислительный путь, пять направлений,
агенты разной стоимости, воспроизводимость каждого опыта и общая память.
Проверить действующие первичные источники OpenAI: модели/уровни, AGENTS, skills,
подагенты, память, worktrees, долгие задачи и применение в науке.
Отделить официальные механизмы от рекомендаций команды; не выдумывать переключатели.
Выбрать минимальные проверяемые артефакты и исключить запуск научных GPU-опытов из этой задачи.

## 2. Рабочий план

1. Прочитать текущую структуру и известные несоответствия starter-kit.
2. Собрать реестр источников с датой и решениями, которые они обосновывают.
3. Создать короткий AGENTS, подробные инструкции по требованию, командную MEMORY.
4. Добавить реальные конфигурации Codex и локальные skills, проверить внешний навык.
5. Дать прозрачное научное ядро и ограниченный recorder запуска, не полный ML-framework.
6. Проверить синтаксис, структуру, ссылки, настройки, инварианты тензоров и runner на CPU.
7. Просмотреть diff, подтвердить неизменность старых решений, создать commit и проверить ref.

## Критерии приёмки

Научный путь можно проследить в четырёх коротких файлах. Навыки имеют ясные триггеры,
вход/выход и границы. Каждая роль задаёт модель/effort. Память не содержит придуманных
экспериментальных чисел. Опыт без согласованного плана/чистого дерева не стартует.
Результаты failure сохраняются. Нет новых ключей, оплаченных запросов, загруженных LLM,
переписанных baseline, изменения lockfile и притворной проверки на пользовательском GPU.
Фактические результаты проверки записываются отдельно, не выводятся из этого плана.
