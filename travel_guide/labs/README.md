# Увидеть вычисления, а не только прочитать

[Начало](../README.md). Запускай из корня репозитория в уже настроенном Python-окружении. Первые три примера не скачивают модель, не читают реальные метки и не десериализуют артефакты.

## 1. Контракт: достаточно стандартной библиотеки

```bash
python travel_guide/labs/01_contract.py
```

Настоящие ingestion и scoring работают в отдельных процессах с тремя искусственными задачами. Сначала исходный `always-true` получает `accuracy=2/3`, `coverage=1`. Затем один целочисленный ответ делает невалидными оба примера одной модели: `accuracy=1/3`, `coverage=1/3`. Все временные файлы удаляются. Это проверка формата, а не конкурсный результат.

## 2. Тензор и проба: NumPy + PyTorch

```bash
python travel_guide/labs/02_probe.py
```

Сначала увидишь `[1,4,3] → [3]`, затем margins `[-3.6, 2.4]` и итог `False`. Результат сравнивается с **оригинальной** `mean_ensemble_margin`. Служебный `_repo.load_functions` извлекает только нужные функции из исходника, чтобы не импортировать Transformers. Это прозрачная тестовая изоляция, не подмена формулы и не способ писать production inference.

## 3. Вероятности и признаки: NumPy + PyTorch

```bash
python travel_guide/labs/03_uncertainty.py
```

Две строки, три шага, словарь из четырёх токенов. `gather` выбирает вероятности конкретных токенов, маска удаляет EOS/pad, настоящая функция из `metrics.py` вычисляет признаки. На выходе `[2,14]`; PPL первой строки примерно `1.889822`, второй — `1.666667`. Посмотри, почему число сгенерированных токенов не является пятнадцатым входным столбцом.

## 4. Необязательно: реальный forward на закешированной модели

```bash
python travel_guide/labs/04_cached_model.py --help
```

Только после подготовки весов и оценки доступной памяти:

```bash
python travel_guide/labs/04_cached_model.py --model-id deepseek-ai/DeepSeek-R1-0528-Qwen3-8B --device cuda --layer -1
```

Этот пример требует Transformers и подходящую машину. Он не скачивает недостающие веса, не использует pickle и печатает реальные формы каждого hidden state. По умолчанию устройство CPU; для указанной команды нужна CUDA. Это **не** обещание, что 8B checkpoint поместится на любой видеокарте. Промпт здесь учебный, не обязательно совпадает с промптом обученного probe. Реальный forward не входит в лёгкие тесты и при подготовке guide не выполнялся.

## Проверки и вспомогательные файлы

```bash
python travel_guide/tools/check_guide.py
python -m unittest discover -s travel_guide/tests -v
```

`_repo.py` — вспомогательная загрузка доверенных исходников для примеров. `tools/normalize_cases.py` — явный локальный обход [ошибки схемы импортёра](../reference/pitfalls.md). `tools/check_guide.py` — проверка ссылок, Python-синтаксиса и эквивалентности аннотированных функций. Тесты проверяют контракт, конвертер и численные пограничные случаи; это не полный тест LLM/submission.
