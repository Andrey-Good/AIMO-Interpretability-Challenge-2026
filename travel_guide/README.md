# AIMO: путеводитель по коду

**Входные знания: Python, NumPy и PyTorch.** Здесь мы разбираем не обучение большой языковой модели, а систему, которая по её внутренним сигналам предсказывает устойчивость на математической задаче.

## Читать по этому маршруту

1. **[Контракт и путь одной задачи](route/01-contract.md)** — кто вызывает твой код, что в него попадает и как получается оценка.
2. **[Representation probe](route/02-probe.md)** — от текста до вектора, затем до `bool`. Здесь основная математика линейных проб.
3. **[Uncertainty profiling](route/03-uncertainty.md)** — от распределений следующего токена до 14 признаков и обученного предсказателя.
4. **[Как сделать свой метод](route/04-your-method.md)** — конкретные точки изменений, обучение отдельно от отправки и проверка результата.

Это основной текст. **Справочники и аннотированные фрагменты не нужно читать подряд.** В главах есть ссылки именно туда, где требуется углубление. Формы вроде `[B, T, D]` всегда сопровождаются расшифровкой; размер `D` не угадан, а берётся из модели.

> **Перед настоящим запуском:** в исходном starter-kit есть несовпадение формата данных между импортёром и ingestion. Оно не связано с твоими знаниями. Описание и безопасный локальный обход — в [заметках о несовпадениях](reference/pitfalls.md). Рабочий код соревнования этим guide не исправляется.

## Как устроены пояснения

Оригинальные файлы остаются единственным рабочим кодом. В `annotated/` лежат только выбранные **дословные функции**, к которым добавлены русские комментарии. Это фрагменты для чтения, а не второй submission. Проверка сравнивает их синтаксические деревья с оригиналами, игнорируя комментарии.

Путеводитель привязан к исходникам коммита [`e46be92387081cfb8edf275e573fec7884eb9f32`](https://github.com/Andrey-Good/AIMO-Interpretability-Challenge-2026/commit/e46be92387081cfb8edf275e573fec7884eb9f32). Ссылки на локальные файлы ведут в текущую копию; после обновления starter-kit запускай:

```bash
python travel_guide/tools/check_guide.py
```

Проверка ловит сломанные локальные ссылки, изменения аннотированных функций и синтаксические ошибки. Она **не доказывает** правильность метода или актуальность правил соревнования. [Границы выполненной проверки](reference/verification.md).
