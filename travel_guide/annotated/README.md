# Исходный код с комментариями

[Начало](../README.md). Здесь не нужно читать весь репозиторий второй раз. Открывай нужный фрагмент вместе с соответствующей главой.

**[ingestion_core.py](ingestion_core.py)** — оригинальный `_run`: группировка по модели, строгая проверка ответа и восстановление порядка. [Оригинал](../../components/ingestion_program/ingestion.py).

**[probe_core.py](probe_core.py)** — `_layer_index`, `_encode_problem`, `mean_ensemble_margin`: выбор слоя, срез `[D]`, формы весов и усреднение. [Оригинал](../../solutions/trained-probe/probe_inference.py).

**[collector_core.py](collector_core.py)** — методы `GenerationConfidenceCollector.__call__` и `compute_features`: задержка на один токен, `gather`, последний шаг и маска. Показаны только два метода класса; его инициализация остаётся в оригинале. [Оригинал](../../solutions/uncertainty-profiling/uncertainty_profile/extraction.py).

Это **аннотированные выдержки**, не самостоятельные модули метода. Вспомогательные функции и импортируемые типы остаются в оригиналах; при прямом запуске выдержка выдаст пояснение вместо попытки загрузить модель. Рабочие функции нужно вызывать из исходного решения. Запускаемые учебные программы лежат отдельно в [labs](../labs/README.md).

Комментарии начинаются с `# GUIDE:`. Ни одна исполняемая строка внутри скопированных функций не заменена псевдокодом. [Карта соответствия](source_map.json) позволяет [проверке guide](../tools/check_guide.py) сравнить AST каждой функции с актуальным исходником без его исполнения. После обновления исходника сначала обнови пояснения и выдержки, а не отключай проверку.
