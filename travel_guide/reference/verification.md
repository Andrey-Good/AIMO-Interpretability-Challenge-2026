# Что проверено, а что нет

[Начало](../README.md). Проверка проведена 5 сентября 2026 года относительно исходного коммита `e46be92387081cfb8edf275e573fec7884eb9f32`.

## Выполнено

**22 проверки guide прошли на CPU.** Они проверяют преобразование cases без перезаписи, знаменатель accuracy, структурные ошибки, форму и усреднение проб, NLL/PPL/Min-K, граничные вероятности, пустой ответ, завершение online collector и соответствие аннотированных функций исходникам. [Код проверок](../tests/test_guide.py).

**Три лёгких лабораторных примера запущены успешно.** Первый использует настоящий ingestion и scoring на искусственных данных: валидный always-true даёт accuracy `2/3`, coverage `1`; один неправильный тип в двухэлементном вызове даёт accuracy `1/3`, coverage `1/3`, два invalid. Второй сопоставляет ручной PyTorch-расчёт с NumPy-функцией probe: средний margin `−0.6`. Третий вызывает настоящую функцию uncertainty-метрик и получает `[2,14]`; ожидаемые PPL — примерно `1.889822` и `1.666667`.

Проверены синтаксис добавленных Python-файлов, локальные файловые ссылки и шесть выбранных функций через AST. Для ссылок на отсутствующие в локальной рабочей выборке файлы использовано дерево исходного GitHub-коммита. Внешние URL и якоря заголовков автоматическая проверка не обходит.

## Границы результата

Исходники получены через GitHub и локально восстановлены для проверки. Полные тексты `ingestion.py`, `scoring.py`, `always-true/solution.py` и `metrics.py` дополнительно сверены по Git blob SHA. Численные функции probe и два метода collector проверялись отдельно, без импорта полного Transformers-модуля; это явно видно в test helper. Такой запуск проверяет показанные операции, **не весь inference-стек**.

LLM, её веса и GPU inference не запускались. Не запускались обучение на настоящем датасете, конкурсный Docker-контейнер, загрузка бинарных `.pkl`/`.joblib` и отправка на Codabench. Не утверждается, что полный набор исходных тестов зелёный: [известные несовпадения starter-kit](pitfalls.md) сохранены, а не замаскированы.

Опциональный [пример с закешированной моделью](../labs/04_cached_model.py) подготовлен, но реальный model-forward здесь не проверен. Его запуск требует совместимых библиотек, локального checkpoint и достаточной памяти.

## Повторить в своей копии

Из корня репозитория, в окружении с NumPy и PyTorch:

```bash
python travel_guide/tools/check_guide.py
python -m unittest discover -s travel_guide/tests -v
python travel_guide/labs/01_contract.py
python travel_guide/labs/02_probe.py
python travel_guide/labs/03_uncertainty.py
```

Только первая команда и первая лабораторная не требуют NumPy/PyTorch. Веса моделей и сеть этим пяти командам не нужны. Проверки не меняют исходные решения и не обучают конкурсный метод.
