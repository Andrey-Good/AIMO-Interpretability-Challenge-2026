# Состояние проекта

Обновлено: 2026-09-07. Статус: подготовка исследовательского процесса.

Команда из пяти человек. Направления: варианты формулировок; глубина слоёв;
генерация/уверенность; предсказатели; корректность проверки.
Принцип: человек определяет вопрос и понимает features/predictor, агент реализует обвязку.

**Подтверждённых научных результатов AIMO в этой памяти пока нет.**
Предыдущие числа в переписке были иллюстрациями, не результатами опытов.
Имеется starter-kit и travel_guide; известные несовпадения перечислены в
`travel_guide/reference/pitfalls.md`. Перед настоящим запуском сверить их с текущим кодом.

Добавлено: правила/навыки/конфигурации, прозрачное ядро и runner.
Не сделано: загрузка датасета/LLM, реальная проверка на GPU, готовая отправка,
калибровка расходов Astra/Terra/Luna на аккаунте пользователя.

Следующий шаг: аудит фактически доступных данных, групп задач и оборудования;
утвердить разбиение и один маленький опыт до большого извлечения активаций.
GPU/API-бюджет не выдан; образец плана не разрешает запуск.
См. `docs/agents/VERIFICATION.md` для технических проверок этого изменения.
