# Журнал опытов

Runner создаёт `<run_id>/execution.json`: команда, code_sha, хеш плана, время,
статус процесса, ссылки на локальные журналы и контрольные суммы ожидаемых файлов результата.
Научный итог дописывается в `<run_id>/report.md` после проверки реальных метрик.
Секретные данные удалить из публичного отчёта **до коммита**, не из первичного опыта.

Шаблон report: вопрос; baseline; данные/разбиение; что меняли; измеренные показатели;
расход; контрольные проверки; отрицательные результаты; ограничения; вывод;
следующая различающая проверка; проверивший. Не выводить качество из одного exit code.

Завершённые попытки не перезаписываются; runner обновляет только статус текущего running-запуска. Исправление ошибочного вывода — новая запись со ссылкой
на прежнюю; сбойный запуск не исчезает после удачного повтора.
