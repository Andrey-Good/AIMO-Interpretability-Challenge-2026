# Передача контекста

Один файл `<task_id>-<role>.md` на исполнителя; общий STATE не редактируется параллельно.

Указать: цель; ветка/worktree; code_sha; изменённые пути; что действительно запущено;
результат и ссылки; неудачи; оставшиеся блокеры; команда продолжения; что запрещено;
оставшийся согласованный бюджет. Не включать скрытые рассуждения или весь чат.
Если передача только о плане, явно написать «не запускалось».
