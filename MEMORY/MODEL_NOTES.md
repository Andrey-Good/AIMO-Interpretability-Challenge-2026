# Наблюдения о моделях

Нет подтверждённых измерений для исследуемой LLM.

Не смешивать исследуемую LLM (например checkpoint из AIMO) с агентом-разработчиком
(Astra/Terra/Luna). Для заметки об исследуемой LLM указать checkpoint revision,
шаблон/слои/данные/run_id. Для агента — модель, effort, версию клиента, задачу,
измеренное время/расход/ошибки и повторения. Не записывать впечатление как benchmark.

Шаблон записи:

```text
ID / дата:
Какая модель и revision:
Статус: hypothesis | observed | replicated | refuted | unknown
Утверждение и границы:
Доказательства: run_id, code_sha, путь/контрольная сумма
Альтернативное объяснение:
Что проверено / что ещё не проверено:
Кто проверил:
```
