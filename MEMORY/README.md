# Командная память исследования

Это **соглашение проекта**, не специальная автоматически сканируемая папка OpenAI.
Codex имеет собственную личную память в `~/.codex/memories/`; она не заменяет общие
проверяемые записи. AGENTS явно предписывает читать [STATE.md](STATE.md).

STATE — краткая текущая карта. [DECISIONS.md](DECISIONS.md) — принятые решения.
[MODEL_NOTES.md](MODEL_NOTES.md) — наблюдения о LLM с доказательствами.
[runs](runs/README.md) — по отдельной папке на опыт, включая неудачный.
[handoffs](handoffs/README.md) — незавершённая работа и передачи между агентами.

Пиши факт один раз, в других местах ссылайся. Не копировать беседы и весь stdout.
Каждое научное утверждение: статус, область применимости, run_id, code_sha, ссылка,
ограничения, проверивший. Статусы: hypothesis / observed / replicated / refuted / unknown.
Предсказательность не переименовывается в причинность.

Обновление STATE и DECISIONS делает назначенный интегратор. Остальные пишут независимые
handoff-файлы, чтобы не затереть чужие результаты. После сжатия контекста сначала перечитать
STATE и активную карточку, а не доверять одной фразе из памяти модели.

В публичную Git-память не входят секреты, закрытые условия/ответы/идентификаторы,
личные данные, массивы активаций и веса. Сохранять лишь разрешённые обобщённые результаты,
контрольные суммы и ссылки на доступное команде хранилище. Не делать приватные данные
публичными посредством подробных логов или текста команд.
